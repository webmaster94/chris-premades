# Upstream integration, 2026-11-14

CPR source is integrated through [2.1.8](https://github.com/chrisk123999/chris-premades/releases/tag/2.1.8), commit eb152afac0b9ce81779be9931ae614ef5a2c9180. The maintained legacy branch was reviewed through 17bf19f27. GPS is integrated through [3.0.5](https://github.com/gambit07/gambits-premades/releases/tag/3.0.5), commit 06c97ebc.

CPR adds 143 previously missing item definitions, including more high-level spells, subclass features, equipment and firearm support. See [the inventory](upstream-content.json) for all 257 native definitions. Native helpers use `chris-premades-native`; the legacy catalog retains its identifiers and its NPC Smite/Sneak Attack behavior. CAT remains the sole updater. Existing automatic action injection and BG3 world settings remain owned by the fork to avoid duplicate hooks.

GPS includes region path metadata/crash fixes, actor-preparation recursion fixes, Freedom of Movement source inspection, and 2014 identifier corrections. No new GPS automation was added upstream in this interval. Existing teleport UI and published UUID aliases remain intact.

Both forks now use explicit Midi target counts and views, and retain TokenDocumentSet for workflow mutations. CPR restores serialized remote collections with Midi's API. D&D 6.1's rider deletion values are handled without dropping effect riders or resurrecting removed activities.

Requires CAT 0.1.8, DAE 14.6.9, and Midi 14.6.12 or later. The public Midi 14.6.12 manifest excludes D&D 6.1; the separately maintained Midi update must permit 6.1. These modules do not modify Midi.

Validation is bounded to shared behavior groups: rider flag changes, NPC attack riders in document mode, reaction hit collection mutation, region segment metadata, and synthetic actor source lookup. Existing regression suites and whole-tree syntax/JSON, catalog references, compendium builds and CPR webpack are also checked. No in-game validation was performed.
